# ReadIn — Web

Angular (SSR) web app: standalone components, Signals, NgRx Signal Store, Tailwind CSS, Transloco (ar/en), Tiptap editor.

```text
web/src/app/
├── core/       # auth, http interceptors, i18n, theme, api client, realtime
├── shared/     # ui components, RDoc renderer, directives, pipes
├── layout/     # shell, navigation
└── features/   # auth, onboarding, home, article, editor, comments, profile, ...
```

See [SPEC §7](../docs/SPEC.md#7-web-angular).
